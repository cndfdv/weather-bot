# Telegram-бот с прогнозом погоды

Учебный Telegram-бот на Python, который получает прогноз через OpenWeatherMap, показывает текущую погоду и предлагает рекомендации по одежде.

## Возможности

- текущая погода по выбранному городу;
- прогноз на пять дней и на выбранную дату;
- ежедневные уведомления;
- рекомендации по одежде на основе температуры и осадков.

## Требования

- Python 3.9+;
- токен Telegram-бота;
- API-ключ OpenWeatherMap.

## Установка и запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install aiogram==2.* requests deep-translator
python 'тг бот.py'
```

Перед публикацией или запуском замените ключи в конфигурации на собственные и не храните их в исходном коде или коммитах. Следующий технический шаг для проекта — перенести настройки в переменные окружения.

## Файлы

- `тг бот.py` — точка входа и обработчики команд;
- `города.txt`, `время.txt`, `дни в году.txt` — справочные данные для работы бота.
